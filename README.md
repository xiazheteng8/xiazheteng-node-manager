## 项目介绍

「瞎折腾吧 VPS 多协议节点管理器」是一款面向 Linux VPS 的 Bash 自动化管理工具，目标是将多种节点协议、有证书节点、无证书节点及订阅管理整合到统一的操作入口中。

项目采用简洁的菜单式管理方式，重点减少 VPS 部署过程中重复输入参数、手动修改配置和逐个安装服务的操作。

**核心目标：复制一条命令，进入部署流程，自动完成适用节点的部署，并输出统一订阅地址。**

## 一、一键启动

使用 root 用户登录 VPS，复制以下命令执行：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/xiazheteng8/xiazheteng-node-manager/main/xiazheteng-node-manager.sh)
```

启动后进入管理菜单，根据需要选择部署、节点管理、订阅管理或系统维护功能。

建议使用 Debian、Ubuntu 等常见 Linux 发行版，并确保 VPS 可以正常访问互联网。

## 二、一键部署节点

进入「一键部署节点」菜单后，只需要选择部署模式，无需逐个选择协议。

```text
====================================================
       瞎折腾吧 | VPS 多协议节点管理器
====================================================

  1. 一键部署节点
  2. 节点管理
  3. 订阅管理
  4. 服务状态与故障诊断
  5. 备份与恢复
  6. 更新管理器
  0. 退出

====================================================
```

选择一键部署后：

```text
============== 一键部署节点 ==============

  1. 没有域名
  2. 域名已解析到 203.0.113.10
  0. 返回主菜单

==========================================
```

其中 `203.0.113.10` 为示例地址，实际显示的 IP 由脚本自动检测。

### 1. 没有域名

适用于没有自有域名或暂时不准备配置域名证书的 VPS。

部署流程计划包括：

- 自动检测 VPS 公网 IP。
- 检查系统环境及已有节点服务。
- 部署适用的无证书节点。
- 自动生成节点 UUID、密码或其他必要凭据。
- 检查端口占用，并在条件允许时自动选择其他端口。
- 验证节点配置并启动服务。
- 生成统一订阅地址并输出连接信息。

### 2. 域名已解析到 VPS 的 IP 地址

适用于已经将域名解析到 VPS 公网 IP 的用户。

部署流程计划包括：

- 自动获取 VPS 公网 IP。
- 检查已有域名配置及 DNS 解析结果。
- 检查已有 TLS 证书，必要时申请证书。
- 部署适用的有证书节点及其他兼容协议。
- 自动生成节点凭据、传输参数及连接信息。
- 检查配置并启动相关服务。
- 汇总部署成功的节点，输出统一订阅地址。

域名解析、证书申请及网络端口需要满足相应协议的要求。对于依赖 Cloudflare Argo 隧道的节点，还需要配置对应的隧道。

## 三、计划整合的节点协议

### 无证书节点

| 协议 | 主要特点 |
|---|---|
| VLESS-REALITY-Vision | 使用 REALITY 传输安全机制，适用于不依赖自有 TLS 证书的部署场景 |
| Shadowsocks | 轻量级代理协议，支持 TCP 或 UDP，具体取决于服务端配置 |

### 有证书及其他传输模式

| 协议 | 主要特点 |
|---|---|
| VMess-WS-TLS | 使用 WebSocket 与 TLS 传输 |
| VMess-WS / Argo | 通过 WebSocket 及相应隧道方案接入 |
| Hysteria 2 | 基于 QUIC 的代理协议，使用 UDP |
| TUIC v5 | 基于 QUIC 的代理协议，使用 UDP |
| AnyTLS | 支持 TLS 传输的代理协议 |

管理器将统一管理上述协议的部署配置、服务状态、节点参数和订阅输出。

不同协议的服务端依赖、传输参数、证书要求及端口类型并不相同，部署时应按协议要求分别生成和校验配置。

## 四、统一订阅管理

部署完成后，管理器应自动整理成功部署的节点，并生成统一订阅地址。

订阅管理包括：

- 查看订阅地址。
- 查看节点连接信息。
- 汇总不同协议的节点。
- 更新订阅内容。
- 检查订阅服务状态。
- 排查订阅无法访问的问题。

订阅内容应以实际部署成功的节点为准，避免生成无法连接的节点链接。

## 五、节点管理

通过统一菜单管理 VPS 上的节点及服务：

- 查看已有节点和运行状态。
- 检查配置文件。
- 查看服务日志。
- 检查端口监听情况。
- 重启或修复指定服务。
- 备份节点配置。
- 恢复指定备份。
- 查看订阅服务运行情况。

节点服务应采用独立配置和服务管理方式，尽可能避免不同协议之间相互覆盖。

## 六、SSH 快捷启动

管理器提供快捷启动命令 `X` 的安装功能。

安装完成后，可以在 SSH 终端直接执行：

```bash
X
```

即可再次进入节点管理菜单，无需重复输入完整脚本路径。

快捷命令依赖原脚本的实际保存路径。如果移动或删除原脚本，需要重新安装快捷命令。

## 七、配置与服务保护

对于已有节点的 VPS，部署过程中应优先检测现有配置，避免重复安装或覆盖运行中的服务。
